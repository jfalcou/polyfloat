Detailed Description

Converts a string to a polyfloat value or to a real, each part rounded to nearest in turn.

Variable Documentation

◆ from_string

#include <polyfloat/module/core/from_string.hpp>

The string holds one of these forms, with an optional sign and letters in either case:

  • a decimal number, .5 and 5. included, and an optional exponent with its sign, e-5.
  • a hexadecimal number after 0x, and an optional binary exponent with its sign, p-4. 0x1.8 reads as 1.5, as strtod reads it, where a C++ literal requires the exponent.
  • "inf", "infinity", or "nan".

The separator may stand between two digits of the significand or of the exponent, as the digit separator ' of C++ does. It is ' by default, the option plf::separator names another one, and '\0' allows none. A separator anywhere else, two in a row included, and every other character make the string malformed. A separator that is a digit, a letter, the point, or a sign makes every string malformed.

Each option is given in its own brackets, and the two combine in either order, plf::from_string[plf::separator = ' '][plf::pedantic](target, s...):

  • plf::from_string[plf::separator = c](target, s...) reads the strings with the character c as their separator.
  • plf::from_string[plf::pedantic](target, s...) returns a std::optional<T>.

Parameters

  • target: eve::as<T>() for a result of type T, which is a scalar or SIMD polyfloat or real.
  • s: the strings to read, of types convertible to std::string_view. Their count is 1 or the number of lanes of T, N for eve::wide<T, N>, and another count does not compile.

Return value

The result is the value the string denotes. The high part is that value rounded to nearest, ties to even, and each next part is the exact rest that the previous parts leave, rounded in the same way. The parts are then normalized as by the constructor of plf::polyfloat, which changes them at a tie of a next part and gives an infinity when their sum rounds past the largest finite value.

Infinities, zeros, and NaNs are read into the high part, with the sign of the string, and the next parts are zero. An infinity and a zero also come from a value whose high part rounds past the largest finite value of the base type or to zero: for double, 1e400 reads as an infinity and -1e-400 as a negative zero.

A register holds the value of a single string in every lane, and the values of several strings in its lanes, the first string in lane \(0\).

A malformed string gives NaN, in its lane alone when several strings are read. Under plf::pedantic, the std::optional holds no value when a string of the call is malformed, so that a malformed string differs from "nan".

Example

#include <iomanip>
#include <iostream>
#include <polyfloat/polyfloat.hpp>
int main()
{
// Strings read exactly into double_real_t<double>, printed at 32 digits.
using d2_t = plf::double_real_t<double>;
auto tenth = plf::from_string(eve::as<d2_t>(), "0.1");
auto grouped = plf::from_string(eve::as<d2_t>(), "3'125'569.000'000'000'000'1");
auto spaced = plf::from_string[plf::separator = ' '](eve::as<d2_t>(), "3 125 569");
auto bad = plf::from_string(eve::as<d2_t>(), "0.1x");
auto checked = plf::from_string[plf::pedantic](eve::as<d2_t>(), "0.1x");
auto lanes = plf::from_string(eve::as<eve::wide<d2_t, 2>>(), "12345678901234567890123456789012",
"3.1415926535897932384626433832795");
std::cout << std::setprecision(32);
std::cout << "tenth = " << tenth << "\n";
std::cout << "grouped = " << grouped << "\n";
std::cout << "spaced = " << spaced << "\n";
std::cout << "bad = " << bad << "\n";
std::cout << "checked = " << (checked ? "a value" : "no value") << "\n";
std::cout << "lanes = " << lanes << "\n";
}

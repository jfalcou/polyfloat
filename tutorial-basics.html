Polyfloat numbers

Naming a type

A polyfloat number over double is written plf::double_real_t<double> or plf::triplereal_t<double>. The _t is not decoration: it is an alias for a polyfoat value.

#include <iostream>
#include <iomanip>
#include <polyfloat/polyfloat.hpp>
int main()
{
// The very same name, on a triple real value.
auto z1 = 2.0 + eve::eps(eve::as<double>()) / 2;
auto z2 = plf::double_real_t<double>(2.0, eve::eps(eve::as<double>()) / 2);
auto z3 = plf::triple_real_t<double>(2.0, eve::eps(eve::as<double>()) / 2, 0.0);
std::cout << std::setprecision(16);
std::cout << "z1 " << z1 << std::endl;
std::cout << "z2 " << z3 << std::endl;
std::cout << "z3 " << z3 << std::endl;
std::cout << "sqrt(z1) = " << plf::sqrt(z1) << "\n";
std::cout << "sqrt(z2) = " << plf::sqrt(z2) << "\n";
std::cout << "sqrt(z3) = " << plf::sqrt(z3) << "\n";
auto after_twisted_init = plf::double_real_t<double>(2.123456e49, 2.4527e+51);
std::cout << "plf::double_real_t<double>(2.123456e49, 2.4527e+51) = " << after_twisted_init << std::endl;
std::cout << "plf::is_normalized(after_twisted_init) = " << plf::is_normalized(after_twisted_init) << std::endl;
}

  • Note the printing convention. A value comes out as a sum of parts that are decreasing in absolute values and that do not overlap. The {non-overlap' thing is mandatory even if we enter a sequence of three perhaps non decreasing and overlapping values, the first thing done by the constructor is to normalize them and the internal represention will always satisfies that every two successive parts x and y (which are standard floating values) will verify x+y == x.
  • z2 and z3 are equal as mathematical real values but applying sqrt does not compute them with the same precision.
  • plf::sqrt(2.0) returns a double. Its argument is a plain double, and the answer is a double, but plf::sqrt(double_real_t<double(2.0) returns a double_real_t<double> which exhibits greater precision.
  • after_curious init retablish the normalized situation. Always use the proper constructor if you provides sequences that does not satisfy the decrease and non-overlap conditions.

Almost all functions you would expect are there, under the name you would expect, in namespace plf, extending EVE. Two hundred of them, from the arithmetic to the elementary math functions. Caveat : up to now, the special functions are still not implemented.

What of invalid values

polyfoat support inf, -inf and (quiet) nan values, the only non zero component of such a value is the high part.

#include <iostream>
#include <polyfloat/polyfloat.hpp>
int main()
{
// The very same name, on a triple real value.
auto z1 = plf::valmax(eve::as<double>());
auto z2 = plf::valmax(eve::as<plf::double_real_t<double>>());
auto z3 = plf::valmax(eve::as<plf::triple_real_t<double>>());
std::cout << "z1 = " << z1 << "\n";
std::cout << "z2 = " << z3 << "\n";
std::cout << "z3 = " << z3 << "\n";
auto zz1 = z1 + z1;
auto zz2 = z2 + z2;
auto zz3 = z3 + z3;
std::cout << "z1+z1 = " << zz1 << "\n";
std::cout << "z2+z2 = " << zz2 << "\n";
std::cout << "z3+z3 = " << zz3 << "\n";
std::cout << "1/(z1+z1) = " << 1 / zz1 << "\n";
std::cout << "1/(z2+z2) = " << 1 / zz2 << "\n";
std::cout << "1/(z3+z3) = " << 1 / zz3 << "\n";
std::cout << "zz1-zz1 = " << zz1 - zz1 << "\n";
std::cout << "zz2+zz2 = " << zz2 - zz2 << "\n";
std::cout << "zz3+zz3 = " << zz3 - zz3 << "\n";
}

What of denormal values

Denormals are treated as well as possible. In fact a denormal has its high part denormal and the others are necessarily 0 because of the decreasing values and the non-overlap properties..

#include <iostream>
#include <polyfloat/polyfloat.hpp>
int main()
{
// The very same name, on a triple real value.
auto z1 = plf::mindenormal(eve::as<double>());
auto z2 = plf::mindenormal(eve::as<plf::double_real_t<double>>());
auto z3 = plf::mindenormal(eve::as<plf::triple_real_t<double>>());
std::cout << "z1 = " << z1 << "\n";
std::cout << "z2 = " << z3 << "\n";
std::cout << "z3 = " << z3 << "\n";
auto zz1 = z1 + z1;
auto zz2 = z2 + z2;
auto zz3 = z3 + z3;
std::cout << "z1+z1 = " << zz1 << "\n";
std::cout << "z2+z2 = " << zz2 << "\n";
std::cout << "z3+z3 = " << zz3 << "\n";
std::cout << "1/(z1+z1) = " << 1 / zz1 << "\n";
std::cout << "1/(z2+z2) = " << 1 / zz2 << "\n";
std::cout << "1/(z3+z3) = " << 1 / zz3 << "\n";
std::cout << "1/(z3+z3) = " << 1 / (-zz3) << "\n";
auto b = plf::triple_real_t<double>(z1, z1, z1);
auto a = plf::triple_real_t<double>(1.0e-20);
std::cout << "a = " << a << "\n";
std::cout << "b = " << b << "\n";
std::cout << "a/b = " << a / b << "\n";
}

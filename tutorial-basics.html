Polyfloat numbers

A floating-point expansion represents a real number as the unevaluated sum of floating-point numbers of decreasing magnitude, which do not overlap. POLYFLOAT represents an expansion of two parts by plf::double_real_t<T>, and one of three parts by plf::triple_real_t<T>, with T either float or double. About two hundred functions apply to them, in namespace plf, under the names of their EVE counterparts: the core functions, from the arithmetic to the predicates, and the elementary functions. The constants, plf::pi, plf::euler for \(e\), or plf::sqrt_2, are given at the precision of each type. The special functions are not implemented yet.

Construction and printing

A value is built by the constructor of plf::polyfloat from as many values as its dimension at most, each converted to its base type, and prints as the sum of its parts, the largest first, the precision of the stream applying to each part. The default constructor gives zero. A single value of a wider type, a double into a polyfloat of float, is split over the parts, and rounded when they hold fewer bits than its mantissa. A constant of EVE or of POLYFLOAT takes the type of its result as an argument, eve::eps(eve::as<double>()) being the machine epsilon of double. A function such as plf::sqrt returns a value of the type of its argument, with the precision of that type:

#include <iomanip>
#include <iostream>
#include <polyfloat/polyfloat.hpp>
int main()
{
// 2 + eps/2 in double, in double_real_t<double>, and in triple_real_t<double>.
auto half_eps = eve::eps(eve::as<double>()) / 2;
auto z1 = 2.0 + half_eps;
auto z2 = plf::double_real_t<double>(2.0, half_eps);
auto z3 = plf::triple_real_t<double>(2.0, half_eps, 0.0);
std::cout << std::setprecision(16);
std::cout << "z1 = " << z1 << "\n";
std::cout << "z2 = " << z2 << "\n";
std::cout << "z3 = " << z3 << "\n";
std::cout << "sqrt(z1) = " << plf::sqrt(z1) << "\n";
std::cout << "sqrt(z2) = " << plf::sqrt(z2) << "\n";
std::cout << "sqrt(z3) = " << plf::sqrt(z3) << "\n";
}

Normalization

The constructors from values normalize their arguments: two successive parts \(x\) and \(y\) of the result satisfy \(x + y = x\) in the base type, two NaN comparing equal. The condition is stronger than the absence of overlap, which \((1, 0.5)\) satisfies and the condition rejects. The parts of a value differ from the arguments of its constructor when these overlap, and plf::is_normalized tests the property:

#include <iostream>
#include <polyfloat/polyfloat.hpp>
int main()
{
// The second part is larger than the first: the constructor reorders and renormalizes them.
auto z = plf::double_real_t<double>(2.123456e49, 2.4527e51);
std::cout << "z = " << z << "\n";
std::cout << "is_normalized(z) = " << plf::is_normalized(z) << "\n";
}

Warning
A part written directly, through plf::hi, plf::md, or plf::lo, can leave the value unnormalized, and the functions then can return wrong results without any error. The constructor from a product type takes its parts as they are, and the constructors from values normalize arbitrary parts.

Mixed dimensions

An operation accepts operands of different dimensions over the same base type, a double being of dimension 1, each operand satisfying plf::concepts::polyfloat_like. The result has the largest dimension, with zero in the missing parts of the other operands, and plf::dimension_v gives the dimension of a type:

#include <iostream>
#include <polyfloat/polyfloat.hpp>
int main()
{
// A double, a double_real_t<double>, and a triple_real_t<double> in one expression.
double x = 0.1;
plf::double_real_t<double> y(1.0, 1.0e-20);
plf::triple_real_t<double> z(1.0, 1.0e-20, 1.0e-40);
auto r = x + y * z;
std::cout << "x + y * z = " << r << "\n";
std::cout << "dimension = " << plf::dimension_v<decltype(r)> << "\n";
}

Infinities and NaN

A polyfloat value represents \(+\infty\), \(-\infty\), and the quiet NaN, whose high part is the special value and whose other parts are zero. The exponent range is the one of the base type, and the arithmetic on the infinities follows IEEE 754. An integer operand is converted to the base type, and can be rounded once its magnitude exceeds \(2^{53}\) for double. plf::rec computes the inverse faster than 1 / y:

#include <iostream>
#include <polyfloat/polyfloat.hpp>
int main()
{
// The largest finite value of each type, doubled past the exponent range of double.
auto x1 = plf::valmax(eve::as<double>());
auto x2 = plf::valmax(eve::as<plf::double_real_t<double>>());
auto x3 = plf::valmax(eve::as<plf::triple_real_t<double>>());
auto y1 = x1 + x1;
auto y2 = x2 + x2;
auto y3 = x3 + x3;
std::cout << "x2 = " << x2 << "\n";
std::cout << "x3 = " << x3 << "\n";
std::cout << "y1 = " << y1 << "\n";
std::cout << "y2 = " << y2 << "\n";
std::cout << "y3 = " << y3 << "\n";
std::cout << "rec(y2) = " << plf::rec(y2) << "\n";
std::cout << "1 / y3 = " << 1 / y3 << "\n";
std::cout << "y2 - y2 = " << y2 - y2 << "\n";
std::cout << "y3 - y3 = " << y3 - y3 << "\n";
}

Denormal values

A denormal high part leaves no room below it for the other parts, which are zero. The second part becomes denormal once the magnitude of the high part falls under \(2^{e_{min} + p}\), \(2^{-969}\) for double and \(2^{-102}\) for float, and the third part \(2^p\) above, \(p\) being the precision of the base type and \(e_{min}\) its smallest exponent. The extra precision decreases from there, and below the smallest positive normal value the high part has fewer bits than the base type. plf::mindenormal of a polyfloat type is the smallest denormal of its base type, in the high part:

#include <iostream>
#include <polyfloat/polyfloat.hpp>
int main()
{
// The smallest positive denormal of double, then a value built from three denormals.
auto d1 = plf::mindenormal(eve::as<double>());
auto d3 = plf::mindenormal(eve::as<plf::triple_real_t<double>>());
std::cout << "d1 = " << d1 << "\n";
std::cout << "d3 = " << d3 << "\n";
std::cout << "d3 + d3 = " << d3 + d3 << "\n";
std::cout << "rec(d3) = " << plf::rec(d3) << "\n";
auto a = plf::triple_real_t<double>(1.0e-20);
auto b = plf::triple_real_t<double>(d1, d1, d1);
std::cout << "b = " << b << "\n";
std::cout << "a / b = " << a / b << "\n";
}

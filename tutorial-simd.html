SIMD support

POLYFLOAT is built on EVE, and every function accepts an eve::wide where it accepts a scalar. An eve::wide<T> is a SIMD register of T, whose operators apply to every lane as they apply to a scalar. polyfloat/polyfloat.hpp also includes EVE, so eve::wide and the constants of EVE need no header of their own.

Note
The EVE documentation and its tutorials cover SIMD programming: the registers, the masks, the algorithms, and the architectures.

Registers of reals

eve::wide<double> holds as many double as a register of the target machine:

  • two on x86-64 with SSE2,
  • four with AVX,
  • eight with AVX-512.

The width is selected at compile time from the target, and the source never names it.

A register is built from a function of two arguments, the lane index and the width, called once per lane, or from one value copied into every lane, eve::wide<double>(2.0). eve::wide<double>::size() is the number of double in the register, x.get(i) reads lane i, and x.set(i, v) writes it. Below, a lambda puts \(-1 + k\) in lane \(k\) and leaves the width unused:

#include <iostream>
#include <polyfloat/polyfloat.hpp>
int main()
{
// Lane i holds -1 + i. The second argument of the lambda, the width, is unused.
eve::wide<double> x = [](auto i, auto) { return -1.0 + i; };
std::cout << "size = " << eve::wide<double>::size() << "\n";
std::cout << "x = " << x << "\n";
std::cout << "x * x = " << x * x << "\n";
}

Registers of polyfloat values

eve::wide<plf::double_real_t<double>> is a register of polyfloat values, with as many lanes as eve::wide<double>. It is built in the same way, and the functions apply to all its lanes, the source differing from the scalar case only by the type of the values:

#include <iostream>
#include <polyfloat/polyfloat.hpp>
int main()
{
// A register of double_real_t<double>, lane i holding -1 + i.
using d2_t = plf::double_real_t<double>;
eve::wide<d2_t> x = [](auto i, auto) { return d2_t(-1.0 + i); };
std::cout << "size = " << eve::wide<d2_t>::size() << "\n";
std::cout << "x = " << x << "\n";
std::cout << "x * x = " << x * x << "\n";
std::cout << "sqrt(x) = " << plf::sqrt(x) << "\n";
}

Generic code

A function template accepts scalars and registers of every dimension with the same body. It is instantiated once for each argument type, and energy below returns a value of the type of its argument, a scalar or a register, of dimension 1, 2, or 3, with no code written per width or per dimension:

#include <iostream>
#include <polyfloat/polyfloat.hpp>
// One body for a scalar or a register, of any dimension.
auto energy(auto z)
{
return plf::sqr(z) + plf::exp(z);
}
int main()
{
using d2_t = plf::double_real_t<double>;
using d3_t = plf::triple_real_t<double>;
std::cout << "double : " << energy(1.0) << "\n";
std::cout << "d2_t : " << energy(d2_t(1.0)) << "\n";
std::cout << "d3_t : " << energy(d3_t(1.0)) << "\n";
eve::wide<double> w1 = [](auto i, auto) { return 1.0 + i; };
eve::wide<d2_t> w2 = [](auto i, auto) { return d2_t(1.0 + i); };
eve::wide<d3_t> w3 = [](auto i, auto) { return d3_t(1.0 + i); };
std::cout << "wide<double> : " << energy(w1) << "\n";
std::cout << "wide<d2_t> : " << energy(w2) << "\n";
std::cout << "wide<d3_t> : " << energy(w3) << "\n";
}

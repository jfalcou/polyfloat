58 //! @defgroup plf_from_string plf::from_string
59 //! @ingroup core
60 //! @brief Converts a string to a polyfloat value or to a real, each part rounded to nearest in turn.
61 //! @{
62 //! @var from_string
63 //!
64 //! The string holds one of these forms, with an optional sign and letters in either case:
65 //!
66 //! - a decimal number, `.5` and `5.` included, and an optional exponent with its sign, `e-5`.
67 //! - a hexadecimal number after `0x`, and an optional binary exponent with its sign, `p-4`. `0x1.8` reads as 1.5,
68 //! as `strtod` reads it, where a C++ literal requires the exponent.
69 //! - `"%inf"`, `"infinity"`, or `"%nan"`.
70 //!
71 //! The separator may stand between two digits of the significand or of the exponent, as the digit separator
72 //! `'` of C++ does. It is `'` by default, the option plf::separator names another one, and `'\0'` allows none.
73 //! A separator anywhere else, two in a row included, and every other character make the string malformed. A
74 //! separator that is a digit, a letter, the point, or a sign makes every string malformed.
75 //!
76 //! @groupheader{Header file}
77 //!
78 //! @code
79 //! #include <polyfloat/polyfloat.hpp>
80 //! @endcode
81 //!
82 //! @groupheader{Callable Signatures}
83 //!
84 //! @code
85 //! namespace plf
86 //! {
87 //! template<typename T, std::convertible_to<std::string_view>... S>
88 //! T from_string(eve::as<T> target, S const&... s);
89 //! }
90 //! @endcode
91 //!
92 //! Each option is given in its own brackets, and the two combine in either order,
93 //! `plf::from_string[plf::separator = ' '][plf::pedantic](target, s...)`:
94 //!
95 //! - `plf::from_string[plf::separator = c](target, s...)` reads the strings with the character `c` as their
96 //! separator.
97 //! - `plf::from_string[plf::pedantic](target, s...)` returns a `std::optional<T>`.
98 //!
99 //! **Parameters**
100 //!
101 //! * `target`: `eve::as<T>()` for a result of type `T`, which is a scalar or SIMD polyfloat or real.
102 //! * `s`: the strings to read, of types convertible to `std::string_view`. Their count is 1 or the number of
103 //! lanes of `T`, N for `eve::wide<T, N>`, and another count does not compile.
104 //!
105 //! **Return value**
106 //!
107 //! The result is the value the string denotes. The high part is that value rounded to nearest, ties to even,
108 //! and each next part is the exact rest that the previous parts leave, rounded in the same way. The parts are
109 //! then normalized as by the constructor of plf::polyfloat, which changes them at a tie of a next part and
110 //! gives an infinity when their sum rounds past the largest finite value.
111 //!
112 //! Infinities, zeros, and NaNs are read into the high part, with the sign of the string, and the next parts are
113 //! zero. An infinity and a zero also come from a value whose high part rounds past the largest finite value of
114 //! the base type or to zero: for `double`, `1e400` reads as an infinity and `-1e-400` as a negative zero.
115 //!
116 //! A register holds the value of a single string in every lane, and the values of several strings in its
117 //! lanes, the first string in lane \f$0\f$.
118 //!
119 //! A malformed string gives NaN, in its lane alone when several strings are read. Under plf::pedantic, the
120 //! [`std::optional`](https://en.cppreference.com/w/cpp/utility/optional) holds no value when a string of the
121 //! call is malformed, so that a malformed string differs from `"%nan"`.
122 //!
123 //! @groupheader{Example}
124 //!
125 //! @godbolt{doc/core/from_string.cpp}
126 //======================================================================================================================

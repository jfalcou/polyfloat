SIMD-Aware Extended Precision Floating-Point

POLYFLOAT is a C++20 library of floating-point expansions. A value is the unevaluated sum of two or three float or double of decreasing magnitude, which do not overlap. It carries two or three times the mantissa bits of its base type, within the exponent range of that type, as Precision details. About two hundred functions of EVE apply to these values, the arithmetic and the elementary functions, and every function accepts a scalar and a SIMD register alike.

Warning
The library is a work in progress: the special functions are not implemented yet.

Features

Precision

A value of plf::double_real_t or plf::triple_real_t keeps the parts of a computation that its base type rounds away. The functions take it under the names of their EVE counterparts, in namespace plf.

#include <iomanip>
#include <iostream>
#include <polyfloat/polyfloat.hpp>
int main()
{
// 2 + eps/2 in double, in double_real_t<double>, and in triple_real_t<double>.
auto half_eps = eve::eps(eve::as<double>()) / 2;
auto z1 = 2.0 + half_eps;
auto z2 = plf::double_real_t<double>(2.0, half_eps);
auto z3 = plf::triple_real_t<double>(2.0, half_eps, 0.0);
std::cout << std::setprecision(16);
std::cout << "z1 = " << z1 << "\n";
std::cout << "z2 = " << z2 << "\n";
std::cout << "z3 = " << z3 << "\n";
std::cout << "sqrt(z1) = " << plf::sqrt(z1) << "\n";
std::cout << "sqrt(z2) = " << plf::sqrt(z2) << "\n";
std::cout << "sqrt(z3) = " << plf::sqrt(z3) << "\n";
}

Mixed dimensions

An operation accepts a float or a double and polyfloat values of different dimensions over the same base type. The result has the largest dimension of its operands, the missing parts being zero.

#include <iostream>
#include <polyfloat/polyfloat.hpp>
int main()
{
// A double, a double_real_t<double>, and a triple_real_t<double> in one expression.
double x = 0.1;
plf::double_real_t<double> y(1.0, 1.0e-20);
plf::triple_real_t<double> z(1.0, 1.0e-20, 1.0e-40);
auto r = x + y * z;
std::cout << "x + y * z = " << r << "\n";
std::cout << "dimension = " << plf::dimension_v<decltype(r)> << "\n";
}

SIMD registers

A function takes one value or an eve::wide of values under the same name.

#include <iostream>
#include <polyfloat/polyfloat.hpp>
int main()
{
// A register of double_real_t<double>, lane i holding -1 + i.
using d2_t = plf::double_real_t<double>;
eve::wide<d2_t> x = [](auto i, auto) { return d2_t(-1.0 + i); };
std::cout << "size = " << eve::wide<d2_t>::size() << "\n";
std::cout << "x = " << x << "\n";
std::cout << "x * x = " << x * x << "\n";
std::cout << "sqrt(x) = " << plf::sqrt(x) << "\n";
}

Options

The functions accept two options, which exclude each other:

  • raw selects the fastest implementation, at the cost of accuracy or of the IEEE 754 results at the edges of the domain,
  • pedantic selects the most accurate implementation, which returns the IEEE 754 results on the infinities, the NaN, and the signed zeros at the edges of the domain.

An option is given between brackets, plf::sqrt[plf::pedantic](x). Most functions behave the same with either option and without it. The reference entry of a function describes the options only when they change its result.

Half-turns

With the option plf::radpi, plf::cos[plf::radpi](x), the functions on angles read and return an angle as a multiple of \(\pi\) instead of radians. A small integer is exact in a polyfloat value, while \(\pi\) is not.

Types

POLYFLOAT defines two types over a base type T, float or double:

Type Dimension Alias of
plf::double_real_t<T> 2 plf::polyfloat<T,2>
plf::triple_real_t<T> 3 plf::polyfloat<T,3>

The SIMD forms take a register as argument:

  • plf::double_real_t<eve::wide<T>> is the type eve::wide<plf::polyfloat<T,2>>,
  • plf::triple_real_t<eve::wide<T>> is the type eve::wide<plf::polyfloat<T,3>>.
Warning
A register of polyfloat values is eve::wide<plf::polyfloat<T,N>>. The type plf::polyfloat<eve::wide<T>,N> is not supported.

Three concepts classify the operands:

  • plf::concepts::polyfloat_like holds for float, double, their EVE registers, and the polyfloat values, which the functions accept, except a few restricted to some dimensions,
  • plf::concepts::polyfloat holds for the values of dimension 2 or more,
  • plf::concepts::real holds for float, double, and their registers, of dimension 1.

References

The representation and the algorithms come from the floating-point expansions of the QD library of Hida, Li, and Bailey, of Joldes, Marty, Muller, and Popescu, and of Zhang and Aiken, and the error-free transformations from the Handbook of Floating-Point Arithmetic and from Graillat and Muller.
